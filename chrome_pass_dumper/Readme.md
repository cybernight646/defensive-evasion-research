README — Educational Security Research Script
Purpose
This script is provided solely for educational and defensive security research.
Its intent is to help demonstrate how modern applications protect locally stored data, how encryption‑at‑rest mechanisms work, and why operating‑system‑level protections are critical.

It is not intended for misuse, unauthorized access, or data exfiltration.

What This Script Demonstrates
Local encrypted data storage concepts
Use of operating‑system protected keys
AES‑GCM encryption structure (IV, ciphertext, authentication tag)
Interaction with SQLite databases
Temporary file handling and cleanup

These concepts are fundamental to understanding secure software design and system security.
