Description
This repository contains a simple Python TCP server and client used to demonstrate basic TCP communication concepts.
The code illustrates how a client can establish a TCP connection to a listening server and exchange data. It is intended purely for learning networking fundamentals such as sockets, connections, and message handling.
This implementation is non-harmful and does not perform command execution, persistence, or exploitation.

Usage
Start the TCP server:
python tcp_server.py
Run the TCP client from the same machine or a reachable host:
python tcp_client.py


Observe the connection, message exchange, and acknowledgment between the client and server.
Notes
This project is intentionally minimal.
It serves as a foundation for understanding how TCP client/server communication works.
Additional features may be added for learning purposes only, such as improved message handling or connection management.
